<objective>
Lay the two foundations every downstream Phase 6 plan needs: (1) the `@tanstack/react-virtual` library plus a proven jsdom test recipe for asserting virtualization, and (2) the Server Action boundary (`actions.ts`) that lets the client `travel-logbook-tab` mutate a persisted logbook and get back both the updated record and the freshly recomputed travel result in a single call.

The virtualization spike de-risks the known React-19/jsdom caveat (research Open Q4 / Pitfall 4) before real tables depend on it.
