PapaParse facts (from research, papaparse.com/docs):
- `Papa.parse<T>(text, { header: true, skipEmptyLines: "greedy", dynamicTyping: false })` returns `{ data, errors, meta }`; `meta.fields` is the header list; `meta.delimiter` is the detected delimiter.
- Leaving `delimiter` unset (default "") enables auto-detection across `,` `;` `\t` `|`.
- `Papa.parse(file, { worker: true, header: true, complete, error })` runs parsing in PapaParse's own internally-managed Web Worker — no manual postMessage plumbing, no dependence on this repo's worker bundling.
- Vitest env is jsdom: `worker: true` cannot run in unit tests — test the sync path; the worker path's config is exercised via the shared config object (see Task 1) and by Phase 6's browser-level checks.
