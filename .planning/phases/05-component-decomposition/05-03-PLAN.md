- REFACTOR — the extracted calculators must produce byte-identical outputs. Rental math (gross×months + otherIncome − ΣexpenseKeys) and Home Office math (ratio = min(office/total,1), monthly = shared×ratio + direct, annual = monthly×12, qualifies = empType !== "salaried") copy VERBATIM.
- Tabs MUST be always-mounted + CSS-hidden, NOT `{tab === "x" && <Tab/>}` (research Pitfall 1). Conditional-mount would reset the calculator's local state on tab switch — a behaviour regression.
- Each extracted calculator holds its OWN `useState` (colocated). Remove the corresponding `rent`/`ho` state and `calcRental`/`calcHO` from the shell.
- Each calculator publishes ONLY via `useSummaryWriter()` (stable setter) and never reads `useSummary()` — reading it would re-couple calculators and reintroduce cross-tab re-renders (research Pitfall 2).
- Remove the shell's now-duplicate `useEffect` publishes for `rentalNet` and `homeOfficeAnnual` (Task 3) so there is exactly one publisher per value.
- Neither of these two calculators needs `useRulePack()` — do not add it.
- Build gate `npm run build` (Turbopack); do not use `--webpack`.
</constraints>
