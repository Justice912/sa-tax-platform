<objective>
Fix the Section 6B additional medical-credit formula in the Medical calculator (CALC-01). Research confirmed two clear SARS breaches in the current code: the under-65 branch uses 3x the medical tax credit (MTC) where SARS requires 4x, and it drops the excess-contributions term entirely (only out-of-pocket is counted). The 65+/disability branch floors the contribution excess before adding out-of-pocket, which is over-generous vs the SARS bracket structure. Section 6A (the monthly scheme-fees credit) is already correct and rulepack-sourced; this plan preserves it and only corrects s6B, then locks the corrected formula with per-year, per-branch regression tests.

Purpose: Bring s6B into line with SARS s6B, with the exact formula pinned by tests so a wrong interpretation fails loudly.
Output: Corrected medical-tab.tsx (math extracted to a testable pure function) + medical-tab.test.tsx.

```typescript
import type { IndividualTaxRulePack } from "@/modules/individual-tax/types";

export interface MedicalCreditInputs {
  dependants: number;
  annualContributions: number;      // monthly contribution x 12
  outOfPocket: number;
  taxableIncome: number;
  age: string;                      // "under65" | "65to74" | "75plus"
  disability: boolean;
}

export function calcMedicalCredits(inp: MedicalCreditInputs, rulePack: IndividualTaxRulePack) {
  const deps = inp.dependants || 1;
  const s6aMonthly =
    Math.min(deps, 2) * rulePack.medicalTaxCredit.firstTwoMembersPerMonth +
    Math.max(0, deps - 2) * rulePack.medicalTaxCredit.additionalMemberPerMonth;
  const s6a = Math.min(s6aMonthly * 12, inp.annualContributions); // s6A unchanged
  let s6b = 0;
  if (inp.age !== "under65" || inp.disability) {
    // SARS s6B (65+ or disability): 33.3% x [ (contributions - 3x MTC) + qualifying out-of-pocket ], no 7.5% floor, sum-then-floor.
    const qual = (inp.annualContributions - 3 * s6a) + inp.outOfPocket;
    s6b = Math.max(0, qual * 0.333);
  } else {
    // SARS s6B (under 65, no disability): 25% x [ (contributions - 4x MTC) + qualifying out-of-pocket - 7.5% x taxable income ], floored at 0.
    const qual = (inp.annualContributions - 4 * s6a) + inp.outOfPocket - 0.075 * inp.taxableIncome;
    s6b = Math.max(0, qual * 0.25);
  }
  return { s6a: Math.round(s6a), s6b: Math.round(s6b), total: Math.round(s6a + s6b) };
}
```
Then replace the component's inline `calcMedical` body so it builds `MedicalCreditInputs` from state (annualContributions = monthlyContrib*12) and returns `calcMedicalCredits(inputs, rulePack)`. Keep all JSX, ResultCards, the Highlight, and the `useEffect(setSummaryValue("medicalTotal", ...))` publish exactly as-is. The three key corrections vs current code: under-65 `3*s6a` -> `4*s6a`; under-65 adds `+ (contributions - 4*s6a)` (previously only out-of-pocket was counted); 65+/disability changes `oop + max(0, contrib - 3*s6a)` to sum-then-floor `max(0, (contrib - 3*s6a) + oop)`.
